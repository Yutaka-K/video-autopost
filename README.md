# 動画自動投稿ツール（YouTube / TikTok / X / Threads）

決めたフォルダに **動画** と **投稿内容.txt** を置いておくと、指定した日時に
**YouTube・TikTok・X・Threads** へ自動で投稿する、Windows 11 用のツールです。

- 投稿の準備は「フォルダを作って、動画とテキストを入れるだけ」
- SNSごとに **オン・オフ** を切り替えられる（キーが未設定のSNSは自動でスキップ）
- 各SNSの **文字数制限に合わせて、投稿文を自動で短く** する
- **お試しモード**：実際には投稿せず、何が投稿されるかだけ表示
- 投稿結果を **ログに記録**、失敗したものは **次回に自動で再挑戦**
- Windows の **タスクスケジューラ** で自動実行

## 1. はじめに準備するもの

- Windows 11 のパソコン
- **Python 3.10 以上**（無料のプログラミング言語。下の手順でインストールします）

### Python のインストール手順
1. <https://www.python.org/downloads/> を開きます。
2. 黄色い「Download Python 3.x.x」ボタンを押してダウンロードします。
3. ダウンロードしたファイルをダブルクリックします。
4. **インストール画面の一番下にある「Add python.exe to PATH」に必ずチェックを入れます。**（とても重要）
5. 「Install Now」を押します。
6. 「Setup was successful」と出たら「Close」で閉じます。

## 2. インストール

1. このツールをダウンロードします。
   - GitHub のページの緑色の「Code」ボタン →「Download ZIP」でダウンロードし、
     ZIP ファイルを右クリック →「すべて展開」で好きな場所に展開します。
   - おすすめの場所：`C:\Users\（あなたの名前）\Documents\動画自動投稿` など
2. 展開したフォルダの中の **「初回セットアップ.bat」** をダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。
   - 必要なライブラリが自動でインストールされます（数分かかります）。
   - 設定ファイル **`.env`** が自動で作られます。
3. 「セットアップが完了しました！」と出たら、何かキーを押して閉じます。

> 💡 `.env` が見えないときは、エクスプローラーの「表示」→「表示」→「ファイル名拡張子」と「隠しファイル」にチェックを入れてください。

## 3. SNSの設定

各SNSのキーの取り方は **[SETUP.md](SETUP.md)** に1ステップずつ書いてあります。

1. SETUP.md を見ながら、使いたいSNSのキーを取得します。
2. `.env` を右クリック →「プログラムから開く」→「メモ帳」で開き、キーを書き込んで保存します。
3. **「設定チェック.bat」** で、使いたいSNSが「OK（投稿できます）」になっているか確認します。

### SNSのオン・オフ
`.env` の次の行で切り替えます（`true` = 使う、`false` = 使わない）。
```
YOUTUBE_ENABLED=true
TIKTOK_ENABLED=true
X_ENABLED=false
THREADS_ENABLED=true
```
キーが書かれていないSNSは、`true` のままでも自動でスキップされます。

### 審査・料金について（大事）
| SNS | すぐできること | 公開投稿するには |
|---|---|---|
| YouTube | 投稿できるが **非公開に固定** | Google の監査（数週間〜2か月程度） |
| TikTok | **「自分のみ」公開** の投稿のみ | アプリ審査＋投稿APIの監査（合計1〜2か月程度）。審査前は **下書きモード** がおすすめ |
| X | すぐに公開投稿できる | 審査不要。ただし **有料**（1投稿 約2〜3円〜） |
| Threads | 自分のアカウントにすぐ公開投稿できる | 審査不要（動画の一時置き場の準備が必要） |

詳しくは SETUP.md の各SNSの「審査について」を見てください。

## 4. 投稿の準備のしかた

### かんたんな方法
1. **「新しい投稿を作る.bat」** をダブルクリックし、投稿の名前（例：`京都旅行`）を入力して Enter。
2. 「投稿待ち」フォルダの中に `京都旅行` フォルダができ、エクスプローラーが開きます。
3. そのフォルダに **動画ファイル**（.mp4 など）を1つ入れます。
4. フォルダの中の **「投稿内容.txt」** をメモ帳で開いて書き換え、保存します。

### 手作業でやる方法
1. 「投稿待ち」フォルダの中に、好きな名前のフォルダを作ります（1投稿＝1フォルダ）。
2. 「投稿待ち\_テンプレート\投稿内容.txt」をコピーして、そのフォルダに入れます。
3. 動画ファイルを1つ入れ、投稿内容.txt を書き換えます。

```
投稿待ち\
├─ _テンプレート\        ← お手本（ここは投稿されません）
│   └─ 投稿内容.txt
├─ 京都旅行\
│   ├─ kyoto.mp4
│   └─ 投稿内容.txt
└─ 料理動画\
    ├─ cooking.mp4
    └─ 投稿内容.txt
```

### 投稿内容.txt の書き方
```
【タイトル】
秋の京都を1日で歩いてみた

【説明文】
紅葉がきれいな京都を、朝から晩まで歩きました。
おすすめのお店も紹介しています。

【タグ】
京都, 旅行, 紅葉, vlog

【投稿日時】
2026-11-15 18:00

【投稿先】
YouTube: する
TikTok: する
X: しない
Threads: する
```

| 見出し | 書くこと |
|---|---|
| 【タイトル】 | 動画のタイトル（必須） |
| 【説明文】 | 説明文。何行でもOK |
| 【タグ】 | カンマ（,）か読点（、）で区切る。`#` は不要。YouTube ではタグ、TikTok・X ではハッシュタグになります（Threads は最初の1つだけ） |
| 【投稿日時】 | `2026-11-15 18:00` の形。**空にすると次の実行ですぐ投稿** |
| 【投稿先】 | SNSごとに `する` / `しない` |
| 【動画URL】 | Threads を manual モードにしたときだけ使います（普段は空） |
| 【Xの投稿文】など | SNSごとに文章を変えたいときだけ書きます（空なら自動で作ります） |

### 各SNSに投稿される文章
- **YouTube**：タイトル＝【タイトル】、説明文＝【説明文】、タグ＝【タグ】
- **TikTok・X・Threads**：「タイトル ＋ 説明文 ＋ ハッシュタグ」をつなげた文章
- **文字数がオーバーする場合は、説明文を自動で短くします**（最後に「…」が付きます）。
  それでも入らない場合は、ハッシュタグを後ろから減らします。

## 5. お試し実行・投稿実行

### お試し実行（おすすめ：最初に必ずやりましょう）
**「お試し実行.bat」** をダブルクリックします。
- 実際には投稿せず、**各SNSにどんな文章で投稿されるか** を表示します。
- 投稿日時がまだ先のものも表示します。フォルダは移動しません。

### 投稿実行
**「投稿実行.bat」** をダブルクリックします。
- 「投稿待ち」の中で、**投稿日時を過ぎたもの** を投稿します（日時が先のものは待ちます）。
- 全部のSNSに投稿できたら、フォルダが **「投稿済み」** に移動します。
- 失敗したSNSがあると、フォルダは「投稿待ち」に残り、**次回の実行で失敗したSNSだけ再挑戦** します
  （成功したSNSには二重投稿しません）。
- `.env` の `MAX_RETRY`（初期設定5回）だけ失敗すると、**「投稿失敗」** フォルダに移動します。
- どのSNSにも投稿できなかった（全部スキップされた）ときは、「投稿待ち」に残ります。

## 6. 自動実行の登録

**「自動実行に登録.bat」** をダブルクリックし、実行間隔を選びます。

- `1`：**1時間ごと**（おすすめ）… 投稿日時から最大1時間以内に投稿されます
- `2`：**1日1回**（時刻を指定）… 例えば `09:00` と入力すると毎日9時に実行

ポイント
- パソコンの電源が入っていて、**ログインしているとき** に実行されます。
- 電源が切れていて実行できなかった場合は、次に起動したときに実行されます。
- 自動実行のときは黒い画面は出ません。結果は「ログ」フォルダで確認できます。
- やめたいときは **「自動実行を解除.bat」** をダブルクリックします。

## 8. 各SNSの制限と注意点

2026年11月時点の情報です。

| | 投稿文の上限 | 動画の条件（主なもの） | その他 |
|---|---|---|---|
| YouTube | タイトル100文字、説明5000バイト、タグ合計500文字 | 縦型・3分以内ならショートとして扱われます | 1日のアップロード数に API の上限あり。`<` `>` は使えないため全角に置き換えます |
| TikTok | 2200文字 | MP4 / WebM / MOV | 審査前は「自分のみ」公開＋非公開アカウントのみ |
| X | 280（日本語は1文字＝2として数えるので **日本語だと約140文字**） | MP4 / MOV、512MB・2分20秒まで | 有料。URL入りの投稿は料金が高い |
| Threads | 500文字、タグは1つ | MP4 / MOV、5分・1GBまで | 24時間で250件まで。動画は公開URLが必要 |

## 9. 困ったときは

| 症状 | 対処法 |
|---|---|
| 「Python が見つかりません」 | Python をインストールし直し、「Add python.exe to PATH」にチェックを入れる |
| 「まだセットアップが終わっていません」 | 「初回セットアップ.bat」を実行する |
| 「スキップ（…が書かれていません）」 | `.env` に該当のキーを書く。SETUP.md を参照 |
| 「投稿内容に問題があります」 | 表示されたメッセージの通りに投稿内容.txt を直す |
| 文字化けする | 投稿内容.txt をメモ帳で開き、「名前を付けて保存」→ 文字コード「UTF-8」で保存 |
| YouTube の動画が非公開になる | 監査前のプロジェクトの仕様です（SETUP.md の YouTube「審査について」） |
| YouTube「ログインが切れました」 | OAuth 同意画面を「本番環境」にしてから「SNSにログイン.bat」でログインし直す |
| YouTube「利用上限に達しました」 | 翌日（日本時間の夕方以降）に自動で再挑戦されます |
| TikTok「非公開アカウントにしか投稿できません」 | TikTok アカウントを非公開にする、または `TIKTOK_MODE=inbox` にする |
| X「料金（クレジット）が不足しています」 | 開発者ポータルでクレジットを購入する |
| X「権限がありません（403）」 | アプリの権限を「Read and write」にしてから、アクセストークンを作り直す |
| Threads「動画の処理に失敗しました」 | 動画の形式（MP4/MOV）・長さ（5分以内）・サイズ（1GB以内）を確認 |
| Threads「HTTP 401」 | トークンの期限切れ。SETUP.md の Threads ステップ5でトークンを作り直す |
| 「投稿失敗」フォルダに移動した | 原因を直したら、フォルダを「投稿待ち」に戻し、中の `投稿結果.json` を削除する |

詳しい記録は「ログ」フォルダの `ログ_年-月.txt` に残っています。

## 10. 安全のための注意

- **`.env`・`client_secret.json`・`tokens` フォルダは、パスワードと同じくらい大事です。**
  他人に送ったり、SNSやGitHubに載せたりしないでください。
- このツールを GitHub で管理する場合も、これらは `.gitignore` で **自動的に除外** されるようになっています。
  動画や投稿フォルダ、ログも除外されます。
- もしキーが漏れてしまったら、各SNSの開発者サイトでキーを作り直してください（Regenerate / 再生成）。

## 11. 開発者向け情報

### 構成
```
run.py                  … 起動用
autopost/
  main.py               … コマンド（run / check / login / new / register-task など）
  runner.py             … 全体の流れ（投稿・記録・再挑戦・移動）
  post_parser.py        … 投稿内容.txt の読み取り
  text_fit.py           … 文字数制限に合わせた自動調整
  scheduler.py          … タスクスケジューラ登録（XML を作って schtasks で登録）
  video_hosting.py      … Threads 用の動画一時置き場（S3互換）
  oauth_helper.py       … ブラウザログインの受け取り（TikTok）
  platforms/
    base.py             … SNS共通の仕組み（Platform クラス）
    youtube.py / tiktok.py / x.py / threads.py
tests/                  … 偽のAPI応答を使ったテスト（実際のSNSには接続しません）
tools/make_bat.py       … .bat を Shift_JIS + CRLF で作るスクリプト
```

### 使っている公式API
| SNS | API | 認証 |
|---|---|---|
| YouTube | YouTube Data API v3 `videos.insert`（再開可能アップロード） | OAuth 2.0（デスクトップアプリ） |
| TikTok | Content Posting API（`creator_info/query` → `video/init` または `inbox/video/init` → 分割PUT → `status/fetch`） | OAuth 2.0 + PKCE（24時間トークンを自動更新） |
| X | X API v2（`/2/media/upload/initialize` → `append` → `finalize` → STATUS → `/2/tweets`） | OAuth 1.0a（ユーザーコンテキスト） |
| Threads | Threads API（`/me/threads` でコンテナ作成 → 状態確認 → `/me/threads_publish`） | 長期トークン（自動延長） |

### 新しいSNSを追加するには
1. `autopost/platforms/` に `Platform` を継承したクラスを作り、`missing_settings()`・`preview()`・`publish()` を実装します。
2. `autopost/platforms/__init__.py` の `PLATFORM_CLASSES` に登録します。
3. `autopost/config.py` の `PLATFORM_NAMES`、`autopost/post_parser.py` の `PLATFORM_ALIASES`、`.env.example` に追加します。

### テストの実行
```bash
pip install -r requirements-dev.txt
python -m pytest
```
テストはすべて偽のAPI応答（モック）を使っており、実際のSNSには一切投稿しません。

### コマンド
```bash
python run.py run --dry-run   # お試し
python run.py run             # 投稿
python run.py check           # 設定確認
python run.py login youtube   # ログイン
python run.py new 名前        # 投稿フォルダ作成
python run.py register-task --hourly       # 1時間ごとに自動実行
python run.py register-task --daily 09:00  # 毎日9時に自動実行
```
